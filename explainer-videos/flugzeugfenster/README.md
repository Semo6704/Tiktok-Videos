# Erklärvideo: Warum sind Flugzeugfenster rund?

TikTok-Erklärvideo (1080×1920, 30 fps, ~58 s, deutsches Voiceover).

- `script.txt` – Sprechertext
- `voice.mp3`, `alignment.json`, `words.json` – ElevenLabs-Voiceover + Wort-Timings
- `music.py` → `music.wav` – selbst generierter Musik-Hintergrund (lizenzfrei)
- `render.py` – rendert Animationen + Wort-für-Wort-Untertitel → `flugzeugfenster.mp4`

Neu rendern: `python3 music.py && python3 render.py`

Vorschlag Caption: *Warum sind Flugzeugfenster rund? ✈️ Die Antwort hat Leben gekostet… #wissen #lernenmittiktok #flugzeug #fakten #erklärt*
